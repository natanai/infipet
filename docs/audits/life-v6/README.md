# Life-v6 visual evidence

The small proof is the default. It contains one infant, four published raw seeds, sixteen milestone views, sixty intermediate views, and128 motion poses:204 scheduled views. Repeated endpoint/pose images are scheduled views, not204 unique rendered frames.

Run from the project root:

```powershell
npx tsx tools/evolution-audit/run.ts --stage proof --run v6-proof-001
```

The manifest freezes source hashes, source artwork, raw seeds and care histories. Rerunning the same command resumes saved cases. Changed engine or audit sources require a new run ID. Failures remain in compressed case records. `--prepare` freezes provenance without evaluating. `--report-only` regenerates reports from saved evidence without reevaluating the current engine.

To rebuild only the audit index, without collecting frames, rendering images, or reanalyzing metrics:

```powershell
npx tsx tools/evolution-audit/run.ts --index-only
```

Percentage-point comparisons require complete review panels, the same frozen cohort and metric definitions, and the exact same reviewed comparison set. Partial panels display their coverage but cannot supply a complete-panel baseline. Presentation corrections are recorded separately; frozen capture manifests retain their original hashes.

Run the focused presentation regressions with `npx tsx --test tools/evolution-audit/comparison.test.ts`.

Use `--stage three` only after the first proof is visually convincing; this expands to bean, sprout and canine-cub. `--stage full` creates1,536 endpoint views from six starters, sixteen raw seeds, four histories and four milestones. It does not silently launch from the default command.

Inspect actual paged PNG/SVG atlases and the filterable HTML gallery. Gallery labels begin blind; reveal seed and history after assessing distinctiveness. Motion loops contain eight procedurally generated held poses. Exact ages, activities, times and view hashes are saved.

`visual-reviews.json` begins explicitly unreviewed. For each reviewed adjacent-stage comparison, record reviewer identity/kind,0–3 scores and specific defects. Multiple independent records may refer to the same comparison. Distinctiveness anchors:0 unchanged;1 minor variant;2 clear evolved form;3 major reorganization. Feature coherence, richness and continuity use the same0 absent/broken to3 strong anchors. A numeric silhouette alert does not complete visual review.

This protocol reuses tested normalized morphology descriptors, separately versions its interpretation, and records helper hashes. Color changes, translation, uniform scale and whole-creature rotation are nuisance transforms. Size, movement and feelings remain separate. Pixel topology is diagnostic, never proof of a meaningful anatomical operation.

The previous household baseline remains provisional. Changed metric definitions are incomparable until both versions are recomputed. Physical iPhone performance, signed widgets and human review remain separate checks.
