Developer inspection only; **no human acceptance is recorded**. The three PNG sheets contain 90 actual renderer frames: six authored presets, three fixed unfiltered seeds, and biological hours 0, 9, 57, 129, and 201. Neutral needs and prescribed stage summaries isolate rendering. These are not screenshots or a complete gameplay-care run; in particular the prescribed advanced summary does not prove the real game's 15-battle/80%-win gate was satisfied.

The source IDs, nonempty facial parts, exact frame hashes, route commitments, data versions, and recipe are recorded in `lineage-render-audit.json`. The sibling TypeScript script reproduces the sheets. Every original source identity remains represented in all 90 frames, and no eye or mouth part becomes empty. Arbitrary seek order reproduced the rendered pixels exactly. The renderer's existing substantial reorganizations, hollow/enclosed stages, and occasional upright or inverted adult forms remain visible; preservation of source identity does not establish aesthetic quality.

The new lineage layer currently adds broad directional modifiers. It does not reconstruct the anatomy of the named clade. For example, seed 02 directs Cub, Sprout, and Ribbon toward Arthropoda while retaining their authored character. Initial placement can currently return only Metazoa or Bilateria. Fourteen of the eighteen source/seed cohorts reach a terminal supported profile at their first branch and retain that affinity through later game stages while procedural morphology continues changing. More specific trait recognition and deeper non-chordate route profiles remain future work.

The hour-zero hatchling commitment was checked against a real `createGame` result and does not advance the initial lineage anchor. Gameplay inputs remain unchanged by advancement; normalized development context survives JSON save/validation/reload; exported context arrays do not alias persisted game state. These checks establish software replay behavior, not reference-device fidelity.

The raw animal subtree retains its full represented coverage. The runtime has only the 57-node ancestry closure joining its 19 supported profiles. Unknown or unbundled raw taxon IDs return no runtime profile; any statement that the runtime resolves every raw taxon would be incorrect. Full raw-node traversal belongs in the offline data pipeline.
