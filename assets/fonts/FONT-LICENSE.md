`Web437_DOS-V_re_ANK16.woff` is the exact font used by [Pre-Programmed](https://github.com/natanai/pre-programmed/blob/main/src/Web437_DOS-V_re_ANK16.woff). `DOS.ttf` contains the same font tables, losslessly decompressed from that WOFF1 file into a TrueType sfnt container for iOS and Android compatibility. Glyphs, names, hinting and metrics are unchanged. The sfnt checksum adjustment was recalculated. This format conversion is distributed under the same CC BY-SA 4.0 license.
